# 資料品質保證

FinMind 的資料來自官方公開揭露管道。為了確保您拿到的每一筆資料都與官方來源一致，我們建立了一套持續運作的驗證機制，並把每月的驗證結果公開在[資料品質總覽](index.md)。

## 我們如何確保資料品質

<div class="dq-pillars" markdown>
<div class="dq-pillar" markdown>
<span class="dq-pillar__no">01</span>
**與官方來源交叉核對**

抽樣代表性代號與期間，將 FinMind 的數字與官方公開揭露的同一數字逐格核對，計算一致比例。
</div>
<div class="dq-pillar" markdown>
<span class="dq-pillar__no">02</span>
**每月全面檢測**

每月對資料集執行 9 項自動檢測，涵蓋更新時效、交易日涵蓋、官方來源與跨資料集核對、查詢一致性與數值一致性，全程只透過公開 API 進行。
</div>
<div class="dq-pillar" markdown>
<span class="dq-pillar__no">03</span>
**依官方來源即時更新**

官方來源若有更新或補充，我們會同步更新資料，並在[更新公告](../WhatIsNew.md)說明，各資料集報告也會列出對應的資料維護紀錄。
</div>

## 檢測項目

每個資料集依資料性質適用下列項目；不適用的項目（例如清單型資料沒有交易日涵蓋）會標示為「不適用」。

| 檢測項目 | 檢測方式 |
|---|---|
| 資料更新時效 | 比對最新資料日與最近交易日（或應有期別），確認資料依發布週期同步更新。 |
| 交易日涵蓋率 | 依官方交易日曆抽樣（最近一段期間＋歷年每年抽樣），逐日查詢全市場資料筆數，確認每個交易日都有資料，且筆數與鄰近交易日水準相當。 |
| 補行交易日涵蓋 | 逐日查詢期間內所有週六補行交易日，確認資料完整涵蓋，且筆數與前一交易日水準相當。 |
| 與官方來源一致率 | 抽樣上個月與歷年代表期間（清單型資料則核對現行清單全數），將 FinMind 資料與官方公開揭露的同一數字逐格交叉核對，計算一致比例；國際股價等由資料來源提供的資料，則與資料來源的原始值逐格核對。 |
| 跨資料集一致性 | 以公開 FinMind API 抽樣上個月數個交易日與一個歷史年份，將彼此相關的資料集互相勾稽（例如日成交量與逐筆成交加總、個股法人買賣與市場合計、財報小計與其組成項目），在已知且合理的口徑差異下計算一致比例。 |
| 查詢方式一致性 | 同一天以不同查詢參數（單日、區間、指定代號）各取一次，逐格確認結果一致。 |
| 欄位格式一致性 | 按年度統計數值欄位的小數位數與型別，確認各期間格式一致。 |
| 數值與主鍵一致性 | 確認數量與金額為非負、價格與成交量相互對應、最高價不低於最低價、開收盤落在高低區間、買賣超等於買進減賣出，以及主鍵欄位完整且不重複。 |
| 每日內容獨立性 | 計算每日整日資料的指紋（排除日期欄），確認不同日期的內容各自獨立。 |

## 結果標示

| 標示 | 意義 |
|---|---|
| <span class="dq-pill dq-pill--ok">已驗證</span> | 該資料集本期所有適用項目皆通過。 |
| <span class="dq-pill dq-pill--pass">通過</span> | 該項目本期檢測通過。 |
| <span class="dq-pill dq-pill--note">資料特性說明</span> | 檢測結果反映的是資料本身的特性（例如官方來源開始提供的日期、市場交易制度），報告中附有說明。 |
| <span class="dq-pill dq-pill--na">不適用</span> | 此類資料不適用該項目。 |
| <span class="dq-pill dq-pill--planned">規劃中</span> | 該資料集將於後續納入此項目（目前用於跨資料集一致性）。 |

## 每月更新

- 每月上旬執行一次全面驗證，完成後更新[資料品質總覽](index.md)與各資料集報告，頁首標示本期月份與檢測日期。
- 各資料集報告附有可重現的查詢參數，您可以用自己的 token 呼叫 FinMind API 自行驗證。
- 資料維護紀錄只連結已發布的[更新公告](../WhatIsNew.md)，與公告內容一致。

??? note "抽樣驗證的範圍"

    交易日涵蓋、官方來源一致率等項目採抽樣方式進行，以合理的查詢量涵蓋最近期間與歷年代表日期。報告結論適用於本期抽樣範圍；若您在使用上有任何疑問，歡迎透過[聯絡我們](../Contact.md)與我們聯繫。
