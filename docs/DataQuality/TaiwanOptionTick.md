## 資料特性說明

- 電子選擇權（TEO）、金融選擇權（TFO）等交易量較小的商品，部分交易日整天沒有任何成交，當日逐筆資料為 0 筆（例：TEO 2026-07-02、11-05、11-09～11-11）。檢測以當日行情成交量為 0 確認這類日期屬當天無成交。
- 選擇權成交價的小數位數取決於當時的權利金跳動單位與成交價位：電子選擇權（TEO）在 2025-12-05 以前，權利金較低的契約跳動單位為 0.005 或 0.025 點，成交價可到小數 3 位；2025-12-08 起官方行情最多到小數 2 位。低價契約不一定每天都有成交，因此各年度逐筆成交價的最大小數位數會不同。
