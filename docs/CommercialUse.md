# 商業使用 Q&A

用 FinMind 做產品、服務客戶，看這幾題就夠了。

### 商業用途要選哪個方案？

**Sponsor Pro。** SaaS、AI、App、公司內部系統等商業用途，請選 Sponsor Pro。

### 可以把資料整合進產品對外販售嗎？

**可以。** Sponsor Pro 可以把 FinMind 資料整合進你的產品對外販售。請勿直接轉賣原始資料，或架設鏡像 API。

### 我的使用者也想看即時、分點資料？

**可以。** 讓你的使用者也成為 [FinMind 用戶](https://finmindtrade.com/analysis/#/Sponsor/sponsor)（Sponsor 以上），在你的產品輸入自己的 token，就能直接使用，沒有限制。資料由使用者端以自己的 token 取得；請勿在產品內建你的 token。

### 財報 PDF 可以用在商業產品嗎？

**可以。** 可以下載、分析，用在你的產品與服務中。檔案權利屬原發行公司；用於 AI 檢索、摘要時，請自行評估著作權。

### 需要標示資料來源嗎？

**需要。** 請標示資料來源「FinMind」。
